What is blocked?

Configuration changes, pool/wallet edits, overclocking, firmware uploads and other write operations are denied from the WAN side.

🔁

What remains available?

GET/HEAD access to the AxeOS WebUI and REST API. You can optionally keep the dedicated restart endpoint available.

⚠️

Important

This reduces exposure but does not make Internet-facing mining hardware risk-free. Keep AxeOS, NGINX and your host system updated.

CERTIFICATES

Before enabling the generated config

Your TLS certificate must exist under /etc/letsencrypt/live/YOUR-DOMAIN/. Certificate issuance depends on your DNS/router setup, so the generator does not attempt to automate that potentially destructive step. See the repository README for the Certbot setup.
